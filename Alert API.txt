მარტივად რომ ვთქვათ, Alert არის სისტემური (iOS ან Android) შეტყობინების ფანჯარა.

წარმოიდგინე, რომ შენს აპლიკაციაში მომხმარებელმა დააჭირა ღილაკს „წაშლა“. შენ არ გინდა, რომ ეს მოქმედება უბრალოდ შესრულდეს, რადგან ის შეუქცევადია. ამიტომ, ეკრანზე გამოგაქვს პატარა ფანჯარა, სადაც წერია: „დარწმუნებული ხართ, რომ გსურთ ამ ელემენტის წაშლა?“ და ორი ღილაკი: „კი“ და „არა“.

ეს არის ზუსტად ის, რასაც აკეთებს Alert API.

ის საშუალებას გაძლევს, რომ აჩვენო მომხმარებელს შეტყობინება და სთხოვო მას დადასტურება ან უბრალოდ აცნობო რაღაც მნიშვნელოვანი.

აი, მთავარი პრინციპები:

1. რატომ ვიყენებთ?

    -მნიშვნელოვანი ინფორმაციის ჩვენება: როცა გინდა, რომ მომხმარებელმა აუცილებლად ნახოს შეტყობინება (მაგალითად, „თქვენი ანგარიში დაბლოკილია“).

    -დადასტურების მოთხოვნა: როცა გინდა, რომ მომხმარებელმა დაადასტუროს მოქმედება, რომელიც შეუქცევადია (მაგალითად, „წაშლა“, „გასვლა“).

    -სწრაფი შეტყობინებები: როცა გინდა, რომ მომხმარებელმა სწრაფად მიიღოს ინფორმაცია (მაგალითად, „შეტყობინება გაიგზავნა“).


2. როგორ მუშაობს?

    -შენ იძახებ Alert.alert() ფუნქციას და გადასცემ მას საჭირო პარამეტრებს.

    -React Native ავტომატურად აჩვენებს სისტემურ ფანჯარას (iOS-ზე iOS-ის სტილში, Android-ზე Android-ის სტილში).

    -მომხმარებელი აჭერს ერთ-ერთ ღილაკს, და შენს კოდში სრულდება შესაბამისი მოქმედება.


3. ძირითადი პარამეტრები (Props).

    -title: შეტყობინების სათაური (მაგალითად, „გაფრთხილება“).

    -message: შეტყობინების ტექსტი (მაგალითად, „დარწმუნებული ხართ, რომ გსურთ ამ ელემენტის წაშლა?“).

    -buttons: მასივი ღილაკების შესახებ. თითოეული ღილაკი არის ობიექტი, რომელიც შეიცავს:

        -text: ღილაკის ტექსტი (მაგალითად, „კი“).

        -onPress: ფუნქცია, რომელიც სრულდება, როცა ღილაკს დააჭერენ.


4. მაგალითი:

    import { Alert } from 'react-native'

    Alert.alert(
      'გაფრთხილება',
      'დარწმუნებული ხართ, რომ გსურთ ამ ელემენტის წაშლა?',
      [
        { text: 'არა', style: 'cancel' },
        { text: 'კი', onPress: () => console.log('წაშლა') }
      ]
    )


5. როდის გამოვიყენოთ?

    -როცა გჭირდება მომხმარებლისგან სწრაფი დადასტურება.

    -როცა გინდა, რომ მომხმარებელმა აუცილებლად ნახოს შეტყობინება.

    -როცა გინდა, რომ მომხმარებელმა მიიღოს ინფორმაცია, რომელიც არ უნდა გამოგრჩეს.


6. როდის არ გამოვიყენოთ?

    -როცა გინდა, რომ მომხმარებელმა შეძლოს ეკრანის სხვა ნაწილებზე გადასვლა შეტყობინების დახურვის გარეშე.

    -როცა გჭირდება რთული ფორმა ან მრავალსაფეხურიანი პროცესი.

    -როცა გინდა, რომ მომხმარებელმა შეძლოს შეტყობინების უკან დატოვება და სხვა რამის გაკეთება.


მოკლედ რომ ვთქვათ: Alert არის „სისტემური ფანჯარა“, რომელიც აჩვენებს შეტყობინებას და სთხოვს მომხმარებელს დადასტურებას ან უბრალოდ აცნობებს რაღაც მნიშვნელოვანს.
